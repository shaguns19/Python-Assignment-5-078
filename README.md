# Python Programming Assignment 5

This folder contains 50 separate Python source files (Q01.py through Q50.py) for Assignment 5, covering text-file reading/writing, file modes, file pointers, file statistics and `os` operations.

## Running a program
1. Open the folder in VS Code or a terminal.
2. Run one program at a time, for example: `python Q01.py`.
3. Programs that need a sample file create one if it is missing. Some programs prompt you for a filename or text.

**Caution:** Q43–Q44 and Q49–Q50 rename or delete files. Q50 uses and deletes only its own `temporary_demo.txt`. For other file-management programs, use test files and avoid important files.
